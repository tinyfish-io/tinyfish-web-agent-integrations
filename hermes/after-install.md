# TinyFish installed

**Next:** route Hermes' web tools to TinyFish and verify your key:

```bash
hermes tinyfish setup
```

No key yet? Create one at [agent.tinyfish.ai/api-keys](https://agent.tinyfish.ai/api-keys?source=hermes) — Search and Fetch are free. `setup` will ask for it.

Check anytime with `hermes tinyfish doctor --live` or `/tinyfish-status` in a session.

Signed-in sites: ask Hermes to create a TinyFish profile for a site, sign in at the link it gives you, and `tinyfish_agent` runs as you.

Watch a page, run deep research, or build a dataset: just ask. The bundled `tinyfish:*` skills and `tinyfish_*` tools cover them, each billed under its own credit policy.
