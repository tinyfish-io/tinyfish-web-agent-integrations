# TinyFish installed

**Next:** route Hermes' web tools to TinyFish and verify your key:

```bash
hermes tinyfish setup
```

No key yet? Create one at [agent.tinyfish.ai/api-keys](https://agent.tinyfish.ai/api-keys?source=hermes) — Search and Fetch are free. `setup` will ask for it.

Check anytime with `hermes tinyfish doctor --live` or `/tinyfish-status` in a session.
